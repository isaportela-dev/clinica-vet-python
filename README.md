# 🐾 Vet Clinic System (Python)

A simple command-line veterinary clinic management system built with Python.
This project was developed to practice programming fundamentals such as functions, conditionals, loops, object-oriented programming, and basic data handling.

The system allows users to register, list, search, and remove pets through a console-based interface.

---

# 📚 Features

* Register new pets
* List all registered pets
* Search for a pet by name
* Remove a pet from the system
* Input validation for safer data entry

Each pet stores the following information:

* Pet name
* Species
* Age
* Owner name
